# openmemory-js has moved

This package is deprecated. Install `longmemory` instead:

```bash
npm uninstall openmemory-js
npm install longmemory
```

The `2.x` compatibility release re-exports the LongMemory package and forwards the legacy `opm` command to the `longmemory` CLI.
